Downloaded 22 October 2026. Source SHA256: `63c645a2a863b9972e9a9c2ed576a1de4c390b8475508e1473e69c87a3ee299c`.
The downloaded README is preserved alongside the source as license evidence.
Other avatars in that repository have different, often noncommercial licenses;
none are included here. No third-party avatar runtime library was copied.

Preparation script: scripts/blender/prepare_interviewer.py. Changes: reduced
texture resolution; retained speech/blink/expression morphs; relaxed arm pose;
charcoal clothing; original architectural studio, desk, lighting and framing.
The prepared GLB embeds the skeleton, morphs and texture maps. The human's natural
skin, hair and eye colors are retained; architecture and interface use the six
brand colors. This is a generic fictional character, not a candidate's likeness.
